# 📝 JavaScript Quiz Application

A simple and interactive **Quiz Application** built using **HTML, CSS, JavaScript, and Bootstrap 5**. The application presents multiple-choice questions, includes a countdown timer for each question, calculates the final score, and provides a clean, responsive user interface.

---

## 🚀 Features

* ✅ 10 Multiple Choice Questions
* ⏳ 30-second timer for each question
* 🎯 Automatic score calculation
* 📱 Responsive design using Bootstrap 5
* ➡️ Next button navigation
* 🏁 Displays final score after quiz completion
* 🎨 Modern gradient background with clean UI

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Bootstrap 5

## 📖 How It Works

1. The quiz starts with the first question.
2. Every question has a **30-second timer**.
3. Select the correct option.
4. Click **Next** to continue.
5. If time expires, the application automatically moves to the next question.
6. After the final question, your total score is displayed.
